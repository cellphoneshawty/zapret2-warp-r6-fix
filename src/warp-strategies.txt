# =====================================================================
#  Стратегии zapret2 (winws2) для Cloudflare One Client (WARP)
# =====================================================================
#  Формат строки:  ID | proto | описание | аргументы профиля
#
#  proto:
#    T - TCP (MASQUE h2-only, API). Тестер сам добавит префикс:
#        --filter-l3=ipv4 --filter-tcp=443 --ipset=lists\ipset-warp4.txt --out-range=-d10
#    U - UDP (MASQUE HTTP/3, WireGuard). Префикс:
#        --filter-l3=ipv4 --filter-udp=443,500,1701,2408,4443,4500,8095,8443 --ipset=lists\ipset-warp4.txt --out-range=-n10
#    X - профиль целиком как есть (без префикса), можно с --new
#
#  Блобы (объявлены тестером):
#    tls_max       files\tls_clienthello_max_ru.bin       (из Flowseal, SNI max.ru)
#    tls_google    files\tls_clienthello_www_google_com.bin
#    tls_vk        files\tls_clienthello_vk_com.bin
#    tls_gosuslugi files\tls_clienthello_gosuslugi_ru.bin
#    stun2         files\stun2.bin                          (из Flowseal)
#    quic_google   files\quic_initial_www_google_com.bin
#    game_udp      files\ACTIVE_GAME_UDP.bin                (из Flowseal)
#    fake_default_tls / fake_default_http / fake_default_quic - встроены в winws2
#
#  Соответствие фулингов zapret1 -> zapret2:
#    badseq -> tcp_seq=-10000:tcp_ack=-66000     ts     -> tcp_ts=-600000
#    md5sig -> tcp_md5                           autottl -> ip_autottl=-2,3-20
#    --dpi-desync-repeats=N -> repeats=N         --dpi-desync-fake-tls=! -> blob=fake_default_tls
# =====================================================================
